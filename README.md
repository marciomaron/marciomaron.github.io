# marciomaron.com.br

Blog de análises e notícias tributárias de Márcio Maron. Site estático gerado com [Astro](https://astro.build) a partir do tema [PlainBlog](https://github.com/wutongyuonce/PlainBlog) (licença MIT, em `LICENSE-tema-PlainBlog`), publicado pelo GitHub Pages.

- Como publicar: [GUIA-DE-PUBLICACAO.md](GUIA-DE-PUBLICACAO.md)
- Artigos: `src/content/artigos/`
- Modelo de artigo: `modelos/artigo.md`

Comandos:

```bash
npm install      # instala as dependências (uma vez)
npm run dev      # visualização local em http://localhost:4321
npm run build    # compila o site em dist/
```

Fonte Source Serif 4 (Adobe, SIL Open Font License), em subconjunto latino com versaletes, hospedada em `public/fonts/`.
